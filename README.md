# Planilha-de-Controle-Financeiro-de-Investimento
Planilha de investimento, considerando sugestão de investimento conforme salario, e prospecção de dividendos e patrimonio acumulado ao longo dos anos de acordo com o valor investido. A Planilha conta com uma variação dos valores a serem investidos em cada área em decorrencia do perfil de investidor
